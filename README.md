# 🥩 شيف فرجاني | Chef Fergany
> **سلطان البط البلدي المتبل ومتبلات المشاوي الفاخرة**  
> *سر تتبيلة زمان.. جاهز على نارك في دقايق!*

---

## 🌟 نبذة عن المشروع
منصة وتطبيق ويب متكامل لمطعم ومتجر **شيف فرجاني**، المتخصص في تقديم البط البلدي المتبل الفاخر، ومتبلات المشاوي، وركن الدواجن، وبوكسات التوفير المجهزة بتغليف فاكيوم سحب هواء معقم، مع كيس حراري خاص للفرن وتوصيل مبرد.

---

## ✨ المميزات الرئيسية
* **سلطان السفرة (البط البلدي المتبل روستو ومحشي):** تتبيلة الشيف المعتقة مع أكياس حرارية مخصصة للتسوية الفورية.
* **حاسبة العزومات الذكية (Interactive Gathering Calculator):** حساب كميات اللحوم والطيور بالجرام لعدد الضيوف مع إمكانية إضافة مقترحات العزومة كاملة بضغطة زر واحدة.
* **كتالوج ودليل التسوية (Cooking Modal):** خطوات تسوية دقيقة لكل صنف (الفرن والكيس الحراري • الإيرفراير • الفحم والشواية • الطاسة والجريل).
* **سلة تسوق وتوليد فواتير الواتساب الذكية:** تحويل الطلب تلقائياً إلى رسالة واتساب منسقة ومفصلة برقم الطلب وبيانات المستلم والتوقيت المفضل.
* **تصفح وبحث فوري:** تصنيفات مرنة وبحث ذكي مع تصميم متجاوب 100% للشاشات والموبايل.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)
* **Framework:** [Next.js](https://nextjs.org/) (App Router & Turbopack)
* **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
* **State Management:** [Zustand](https://github.com/pmndrs/zustand) with LocalStorage persistence
* **Icons:** [Lucide React](https://lucide.dev/)
* **Animations & Effects:** [Framer Motion](https://www.framer.com/motion/) & [Canvas Confetti](https://github.com/catdad/canvas-confetti)
* **Language & Fonts:** TypeScript & Google Cairo Arabic Font

## 🚀 تشغيل المشروع محلياً

```bash
# 1. تثبيت الحزم

# 2. تشغيل السيرفر المحلي
npm run dev

# 3. بناء النسخة الإنتاجية
```
